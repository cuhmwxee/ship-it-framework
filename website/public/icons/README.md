# Ship It! icons

`shipit-icon2.png` is the original source for the current logo. `shipit-icon.png`
is its default website copy. Preserve the source image's colors and proportions.

Run `npm run icons` from `website/` to regenerate the default copy and:

- PNG favicons: 16, 32, and 48 pixels
- Apple touch icon: 180 pixels
- Application icons: 192 and 512 pixels
- `app/favicon.ico`: 16, 32, and 48 pixel frames

Previous icons are archived in `v1/`. Previous brand images and guidelines are
archived in `../brand/v1/`.
